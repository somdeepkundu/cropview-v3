# CropView v3

**Geo-tagged field crop capture — monitor crop stages, record ground geometry, and track heading via mobile compass.**

A free, open-source, single-file PWA for field researchers and agronomists. Point your phone at a crop to capture its location, heading, and ground field-of-view, seamlessly matching it to satellite data.

**Version 3.1.0** · RGSTC Project · MIT Open Access License
